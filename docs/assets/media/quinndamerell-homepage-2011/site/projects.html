Projects

The following is a compilation of projects that I have or are currently working on. Click the tittle of the project to find out more information.

PurdueBus - An Android application that provides users the real-time information on Purdue’s CityBus system which operate around Purdue University. Also includes several other features.

Purdue Food Court Menu - An Android application that provides users Purdue food court menus, operation times, locations, and favorites.

Reddit Time Machine - The Reddit Time Machine is a web system that archives the home page of Reddit.com twice every day. And then displays all of the past homepages in an easy to browse fashion.

Zune Playlist Shuffler - Zune Playlist Shuffler is a java based program that does just that, it shuffle manually made Zune playlists. The Zune software alone does not support this feature.

TxtBack - TxtBack is the first major project I have done for the public. Molded off Omegle, TxtBack is a free SMS service that anonymously pairs two random users up for a conversation. Once they are done, the conversation is broken and can be repeated. TxtBack is written in Java and runs on a local server I have here in my drom.

PicGen - PicGen is a java application that can create any black and white picture in the world. Once running, it generates every possible combination of color combination with every other pixel every possible color. Thus it can generate every picture that is nxn pixels.

Purdue Java Projects - This is a directory that is filled with projects i have made in my CS classes at Purdue.

English Final 2008 - This is a collection of different pices that we made for our english final. It is in three parts.

English Final 2007 - This is a Wii TV commercial, newspaper ad, and radio advertisement my friends and I made for our 2007 English final.

Atom Project - 2006, this is a atom project I made for chemisty. I was hard to make, but the outcome was very nice!

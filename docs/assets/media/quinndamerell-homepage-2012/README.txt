QuinnDamerell.com: April 16, 2012 website recovery

Extract the entire ZIP, then open snapshot.html to browse the archived site.
Open archive-index.html for the page list, capture dates, and missing files.
Open history/index.html for the other website versions used in the project review.

Original requested capture:
https://web.archive.org/web/20120416170518/http://www.quinndamerell.com/index.html

The homepage's original HTML is from that exact capture. Wayback saved linked
pages and assets independently. Some recovered images and pages are from later
years; the local pages and manifest.json identify their dates. This is a static
reconstruction of the recoverable site, not a complete simultaneous 2012 backup.

site/ contains the local browseable copies and assets. raw/ preserves recovered
original response bytes, with executable text stored as inert .txt files.
manifest.json records source URLs, capture dates, missing resources, and hashes.
snapshot.png and snapshot.pdf show the reconstructed homepage.

Original scripts, analytics, form submission, Flash players, and server
features are disabled. Audited local helpers restore screenshot galleries,
the rotating header tile, section navigation, and the old video-selection
panels. Photo groups use native expandable sections. The video panels show
the original archived destinations; they do not recreate unavailable video
playback. Header animation respects the browser's reduced-motion preference.

Links to external sites still require an Internet connection. Unrecovered
pages, full-size images, and downloads have local notices; a recovered
thumbnail is shown where available and is identified as a thumbnail.
Recovered fonts are embedded in the served CSS. For the most consistent
browser behavior, view the files through any local static web server.

The history collection is a set of readable source pages and original HTML,
not a whole-site mirror for each historical revision.

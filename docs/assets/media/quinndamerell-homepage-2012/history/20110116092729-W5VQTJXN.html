Here are a few web sites that I have made in my days..
Fort Wayne Decorative Curbing - Nov 06. 2008
 This is a web page that I have made for my dad’s company Fort Wayne Decorative Curbing. This is also a site that I update and change frequently.
 Atom Model in Flash - Oct 16. 2005
 Just click the title and press "run" to view - 1.68MB
 This was a flash projector I made for my chemistry class. You have to download and run it because it is a projector (.exe) but I think it is pretty cool.

 This was a quickly made but kind of cool web site I made for our firework sales. The basic menu system is ok, but the content part sucks!

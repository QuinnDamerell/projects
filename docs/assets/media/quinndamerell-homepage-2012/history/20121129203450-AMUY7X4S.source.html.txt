<h2 id="Features">Features</h2>
<p>Baconit is a modern metro reddit app for Windows Phone. Baconit fully supports Mango, and provides a beautiful , clean, fast, and easy interface to reddit.
Features Include:
<ul>
<li>Beautiful, fast, animated interface</li>
<li>Pinning of subreddits and stories with nightly updating</li>
<li> Beautiful live tiles with full images from subreddits</li>
<li>Flip View to easily browse full screen through a subreddits posts endlessly</li>
<li>BaconSync - synchronized visited links between phones and browsers</li>
<li> Instant loading of any subreddit / reddit url / or search</li>
<li> Message inbox with automatic updates</li>
<li> Unread message / karma live tile</li>
<li> Ability to post / edit / and delete stories and comments</li>
<li>Real-time formatting preview in post submit</li>
<li>Ability to view user profiles</li>
<li> Manage local and account subreddits</li>
<li> Submit links / images to reddit</li>
<li> Hide and save stories</li>
<li>Reddit profile support</li>
<li> Windows phone share picker support</li>
<li> Great light theme support</li>
<li> Endless subreddit scrolling</li>
<li> Fast app switching / multitasking</li>
<li> Local caching of all data</li>
<li> And much, much more….</li>
<li> <a href="ChangeList.html" class="SiteLink">Full change list here</a></li>
</ul>
<h2 id="BaconSync"><a href="BaconSync/index.html" class="SiteLink">BaconSync</a></h2>
<p>BaconSync is a Baconit exclusive technology that synchronizes visited links across all of your devices and browsers. BaconSync also supports sending webpages directly to your phone.
<p>
<a href="BaconSync/" class="SiteLink">Click here for more information on BaconSync and the developer API. </a></p>

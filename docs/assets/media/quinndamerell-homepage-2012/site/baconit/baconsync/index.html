BaconSync

Features. Extensions. API.

Features

BaconSync is an system of browser extensions that work with Baconit for Windows Phone that allows users to seamlessly synchronize visited links on reddit.com between their web browsers and their phones.

Features Include:

  • Seamless synchronization of visited link on reddit.com to and from all of your devices
  • Synchronization across all of your web browsers and Windows Phones
  • Ability to send web pages directly to your phone to be viewed instantly.

BaconSync only works with Baconit for Windows Phone, and will soon be available for all major browsers.

Extensions

Firefox Extension - Created by Pradeek J.

Opera Extension - Created by Ivan Kiselovs

Zune Playlist Shuffler

Microsoft's Zune Player has its upsides and down sides.  Normally the Zune player will not allow you to shuffle non automatically generated playlists.  But don’t fear! I made this simple java program to do just that! Simply download and run this program and you too can be a shuffle manic! Just choose the playlist from the list of playlist and click shuffle, it’s really that simple!

How To Use

Download and double click to run. I recommend you close Zune player if it is open, it will do some weird things as the programs fight for file control. Simply select the playlist in the window, and click shuffle. If the playlist you want to shuffle is not in the window, select Add Directory and guide it to the playlist's directory.

Note: Java is Required to Use this Program

JRE or Java Runtime Environment is required to use this program. Java is a widely used programing language that requires additional downloads to work in windows. Please follow the link and select the version you need. For most users, it will be first program under the Windows heading.

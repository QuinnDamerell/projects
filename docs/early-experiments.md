# Early Experiments & School Projects

Before the mobile apps: homemade animations, first websites, Java experiments, and school projects.

My old [project index](assets/media/quinndamerell-homepage-2011/site/projects.html) and [website index](assets/media/quinndamerell-homepage-2011/site/websites.html), saved in January 2011, kept the descriptions of these alive. Then an old hard-drive backup brought back a lot of the actual work, including these five Flash animations!

## Quincy's Movie Index {#flash-animations}

That was the name of my animation website. Its captions call **Snowman snow fight** the first animation I ever made, and the **3D stick fight** the second. The drawings, timing, and tiny stick figures are exactly as I left them.

Choose a film and press **Play animation**. The original Flash files now run here through [Ruffle](https://ruffle.rs/), with no browser plugin needed.

## Early Websites

- **Animation Website (2004):** my first website, according to the original index.
- **Fireworks Website (2006):** a site for fireworks sales.
- **Crazy Horse (2007):** a web design class final built around supplied images.
- **Fort Wayne Decorative Curbing (2008):** a site for my dad's company. The index dates it November 6, 2008, and notes that I kept maintaining it.

My own site had a small community, too. The [May 2009 homepage](assets/media/quinndamerell-homepage-2012/site/_captures/20090526070712-QVB4AXXJ.html) offered registration and sign-in, plus an **All Users** page with members' Miis and personal mottos.

My [local website backup](assets/media/quinndamerell-homepage-2011/site/local-backup/index.html) brings back the Fireworks and Crazy Horse pages, their original images, and fuller photo galleries. One small mystery: the dates above come from the January 2011 index, but the backup lists Animation, Fireworks, and Crazy Horse as 2002, 2004, and 2005. I'm honestly not sure which is right.

## Java Applets

- **Pong:** written from scratch, with some flaws and glitches I owned up to at the time.
- **Shooter:** an unfinished shooting game. Even the original description wasn't sure it worked.
- **Freezer:** an attempt to freeze the computer that only managed to freeze and shut down the Java runtime.

These were some of my earliest projects. Their compiled Java files survived in the [restored backup collection](assets/media/quinndamerell-homepage-2011/site/local-backup/index.html), but I don't know exactly what year I made them. There's no Java applet player on this site, so they can't run here.

## School Projects

- **Atom Project:** the project index dates this chemistry project **2006**, but the website index lists an **Atom Model in Flash** dated **October 16, 2005**. I'm not sure if they were the same version, so I've kept both dates.
- **English Final (2007):** a Wii TV commercial, newspaper ad, and radio ad made with friends.
- **English Final (2008):** a collection presented in three parts. The index doesn't say what each part was.
- **Purdue Java Projects:** a directory of work from my Purdue computer science classes.

These descriptions come from the index, and I can't promise every original program, video, or assignment still exists.

The [original video index](assets/media/quinndamerell-homepage-2011/site/videos.html), which was also in the backup, still lists all three 2008 video parts and the 2007 commercial. I haven't found the video files themselves, though, so for now they live on as descriptions rather than playable films.

# Instemote

A Windows Phone remote for Insteon lights and scenes.

## Facts

| Created | Status | Code |
| ------- | ------- | --------- |
| 2013    | Retired      | None |

## The story {#description}

Instemote kept smart-home lighting simple: control one light or set the mood for a whole room.

The [device screen](assets/instemote/screen2.png) gave each light on/off buttons and a brightness slider, with examples for a bedroom light, table light, and floor lamp. The [scene screen](assets/instemote/screen1.png) switched named groups together: “All,” “Movie Time,” “Bed Room,” and “Living Room.”

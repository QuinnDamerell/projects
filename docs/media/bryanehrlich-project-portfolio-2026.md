# Bryan Ehrlich's project portfolio

Bryan Ehrlich's portfolio gives his perspective on projects he built with Quinn, including [CrossTxT](../crosstxt.md), [Gathr](../gathr.md), and [PurdueBus](../purdue-bus.md). It preserves a collaborator's account of the problems they tackled and the work behind those early projects. The original tabs are expanded in this static copy so the project accounts remain readable without JavaScript.

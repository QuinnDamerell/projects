# CrossTxT - Welcome to the Texting Revolution

The original [CrossTxT](../crosstxt.md) homepage introduced browser-based texting for Android, with a synchronized inbox and SMS backups. Its five panels explain the service, its features, and how to get started. This version of the original site is no longer live, so this copy comes from the Internet Archive.

The archived page preserves all five panels as selectable tabs; the PDF includes them all. Historical login and signup forms are inactive. The homepage HTML is from October 2011, while the recovered images come from January 15, 2014 captures of the same asset URLs. Some artwork, including the SMS backup illustration, could not be recovered. The [capture metadata](../assets/media/crosstxt-homepage-2011/snapshot.json) records the source dates and missing files.

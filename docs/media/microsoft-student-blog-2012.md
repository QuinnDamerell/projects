# Meet Microsoft developer Quinn Damerell

About four months into his full-time Microsoft job, Quinn talks with Microsoft's Student blog on TechNet about his Raytheon and Windows Phone internships, how [Baconit](../baconit.md) and other apps helped him get hired, a software development engineer's daily work, and advice for students. The original blog is offline; this copy comes from the Internet Archive.

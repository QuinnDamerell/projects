# Meet Quinn Damerell: From developing for Windows Phone to being hired at Microsoft

As he finished at Purdue, Quinn joined Microsoft's Student blog for a Q&A on switching from Android to the Windows Phone SDK to build [Baconit](../baconit.md), overcoming development problems, landing his Microsoft job, and advice for student developers. The blog's [December follow-up](microsoft-student-blog-2012.md) is also archived. The original blog is offline; this copy comes from the Internet Archive.

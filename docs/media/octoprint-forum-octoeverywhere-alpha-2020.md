# New Plugin — OctoEverywhere! — Looking For Alpha Testers!

Quinn's first public [OctoEverywhere](../octoeverywhere.md) announcement invited alpha testers. The discussion records early installation reports and his explanation of the Python plugin and C# service. The live forum presents an automated-access challenge, and its Internet Archive replay did not render correctly. This readable transcript uses the archived page's public data and preserves all 13 posts supplied by that capture.

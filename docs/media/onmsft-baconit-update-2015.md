# Baconit app gets a bunch of new features in major update

OnMSFT's rundown of Baconit 4.2.0 for Windows 10: subreddit sidebars and search, real-time formatting when writing posts, a rewritten Markdown renderer that Quinn open-sourced, Flip View improvements, and comment tweaks. It embeds the update's announcement video. See [Baconit](../baconit.md) for more about the app.

# FTL To Be Officially Supported In OBS Going Forward

Keith Mitchell covers Mixer's FTL streaming integration into official OBS builds, naming Quinn as the developer announcing the change. The article describes the early alpha release and the improvements it would bring to streamers, including simultaneous local recording and streaming. See [Quinn's Mixer work](../career/index.md#microsoft-mixer) and the [official release record](https://github.com/mixer/obs-studio-ftl/releases/tag/v1.0.0), published by QuinnDamerell-MS.

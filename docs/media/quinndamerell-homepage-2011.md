<summary id="about-this-copy">About this copy</summary>

This version predates the tile-based homepage. Its project collection includes [Liquid Physics](../liquid-physics-wallpaper.md), [Purdue Bus](../purdue-bus.md), [Purdue Menu](../purdue-menu.md), [Reddit Time Machine](../reddit-time-machine.md), [Zune Playlist Shuffler](../zune-playlist-shuffler.md), [PicGen](../picgen.md), and [early websites and school projects](../early-experiments.md).

The homepage source is the exact requested capture, preserved alongside the local browsing copy. Wayback saved linked pages and images independently, so their capture dates can differ. Each local page identifies its capture, and the [file inventory](../assets/media/quinndamerell-homepage-2011/archive-index.html) records recovered files and gaps.

Navigation, photo categories, and recovered-image galleries work locally. Larger photos recovered from my backup now open from the original gallery, with links explaining their source. The [recovered galleries](../assets/media/quinndamerell-homepage-2011/site/local-backup/photos.html) also include the Miss Indiana productions from 2007–2010. The video tabs preserve their original YouTube links; those video binaries are still missing. The [early experiments](../early-experiments.md#flash-animations) now include playable original Flash animations. Sign-in, contact forms, Java applets, and features that depended on the original server remain unavailable. Original Java files are preserved as downloads.

The local backup includes the Fireworks and Crazy Horse websites, PicGen's screenshot and product page, and Zune Playlist Shuffler 1.3. Its historical dates sometimes differ from the Wayback copies; neither has been silently rewritten. The download includes the browsing copy, local supplements, inert source text, and provenance records. PHP backend code and credentials are not included.

# Microsoft's Windows Phone student developers: building an ecosystem

Tom Warren spoke with student developers building for Windows Phone. His feature includes Quinn's experience making [Baconit](../baconit.md), the opportunities Microsoft offered students, and the challenges of contributing to a young mobile ecosystem. The live page was unavailable in full during archiving, so this copy comes from the Internet Archive. The article’s photographs were restored from The Verge’s current image host. The screenshot taken before restoration is also retained.

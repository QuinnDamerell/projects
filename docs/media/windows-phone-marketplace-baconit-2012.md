# Baconit on the Windows Phone Marketplace

This early [Baconit](../baconit.md) **1.7.0.0** listing preserves eight screenshot thumbnails, features, and contemporary user reviews. It names Quinn Damerell as publisher and Windows Phone 7.5 as the minimum requirement. The store lists December 14, 2011 as the release date, though that may not be when version 1.7.0.0 shipped. The original Windows Phone Marketplace is offline; this copy comes from the Internet Archive.

# Reddit users, your Baconit is here

Windows Central's announcement that [Baconit](../baconit.md) had left beta and gone live in the Windows Phone Marketplace. Written when most Reddit apps still hadn't been updated for Windows Phone 7.5 (Mango), it walks through the app's features, calls it one of the best Reddit apps the site had tried, and congratulates Quinn on returning to Microsoft to join the Windows Phone team.

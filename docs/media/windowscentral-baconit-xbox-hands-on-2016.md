# Hands on with Baconit for Xbox One

Windows Central tried [Baconit](../baconit.md) on Xbox One, showing how its Reddit browsing experience translated to a television and controller. The hands-on includes interface images and discusses the shared Windows codebase behind the console and mobile versions.

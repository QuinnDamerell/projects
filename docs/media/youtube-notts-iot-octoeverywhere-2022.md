# Enabling OctoPrint for 3D Printing Everywhere

Quinn joins Notts IoT to share the engineering behind [OctoEverywhere](../octoeverywhere.md): turning a prototype into a service, running a worldwide server mesh, and adding AI print failure detection. The full meetup recording includes the opening announcements and discussion; Quinn's presentation is underway around 12:49.

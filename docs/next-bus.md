# Next Bus - A CityBus App for Windows Phone

Live CityBus arrivals for Boilermakers and anyone riding around Greater Lafayette.

## Facts

| Created | Status | Code |
| ------- | ------- | --------- |
| 2011    | Retired      | None |

## The story {#description}

Next Bus covered every CityBus stop across Purdue's campus, West Lafayette, and Lafayette. Its live map centered on the rider and highlighted nearby stops. Stop Viewer listed every route loop serving a stop and refreshed arrival times every 30 seconds.

Riders could search by stop code, such as BUS156, and pin stops to the Windows Phone Start screen. The [stop viewer](assets/next-bus/Screen.png) shows route names and minutes until arrival; the [Start screen](assets/next-bus/Screen2.png) shows saved-stop tiles beside the main app tile. The app supported Mango and fast app-switching.

### Campus History

In March 2012, I was still [telling fellow Purdue students about Next Bus](media/reddit-next-bus-introduction-2012.md#comment-c3xv7sw). Fun fact: Purdue Chemical Engineering's [Summer 2019 new-student manual](https://web.archive.org/web/20190922140129/https://engineering.purdue.edu/ChE/academics/graduate/new-graduate-student-manual#page=6) was still recommending it to Windows users, though I'm not sure how long the service actually kept running.

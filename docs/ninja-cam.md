# Ninja Cam

A Windows Phone camera app disguised as a webpage.

## Facts

| Documented by | Platform | Code |
| ------------- | -------- | --------- |
| March 2012 | Windows Phone | Recovered from my backup; unpublished |

## The story {#description}

Ninja Cam was a camera app in disguise. Instead of a camera preview, it showed an interactive fake webpage. Tap the screen and it quietly snapped a photo with the rear camera and saved it to the Camera Roll, while anyone looking just saw ordinary web browsing. It sat alongside Baconit and Next Bus on my original homepage, and the [Marketplace listing](https://web.archive.org/web/20120316213100/http://www.windowsphone.com:80/en-US/apps/37ce9ea8-0c67-48b6-bd2a-ab055855eb49?) still has my original description.

<details class="qd-story-details" markdown="1">
<summary>Version, compatibility, and early reviews</summary>

The Marketplace page, as saved on March 16, 2012, lists a free, English-language app for Windows Phone 7.5 or later:

- **Version:** 1.5.0.0.
- **Download:** 1 MB.
- **Release date listed:** February 29, 2012 (this may have been an update rather than the first release).
- **Also saved:** six early ratings and three screenshot references.

Someone asked for video recording, but my description only mentions still photos.

My backup also has an unfinished **Windows 8 port**. It starts a camera preview and recreates the browser disguise, but the capture button is still a placeholder that just writes some text to a file you pick. As far as I know, it was never released.

</details>

# QWorld

A creepy carnival, birthday riddles, and a finale that made friends crack a code to talk.

## Facts

| Created | Status | Code |
| ------- | ------- | --------- |
| 2013    | Retired      | None |

## The story {#description}

I made QWorld for a friend's birthday: a one-off adventure mixing D&D with escape-room puzzles, led by a dungeon master. The group entered a creepy carnival and solved riddles to move forward.

For the finale, I split the players into two Discord channels so they couldn't talk directly. Each team received a secret word for the other team to guess. Their only connection was a custom web messenger that scrambled every message with a cipher. Before they could coordinate, they had to crack the code.

# Zune Playlist Shuffler

A small Java utility for a missing Zune feature: shuffling the order of a playlist.

## Facts

| Documented by | Platform | Language |
| ------------- | -------- | -------- |
| April 2010 | Microsoft Zune desktop playlists | Java |

## The story {#description}

Pick a playlist you made by hand in the Zune desktop app, click **Shuffle**, and get a fresh order. **Add Directory** found playlists stored outside the usual location. The instructions recommended closing Zune first so the two programs wouldn't write to the same playlist at once. Version 1.3 was a tiny 18.3 KB Java archive.

I [shared it with r/Zune on April 28, 2010](media/reddit-zune-shuffler-launch-2010.md), with a title explaining that I'd made it for myself and thought others might like it too. The post linked to `quinndamerell.com/ZuneShuffler/`, so it was public by then, even before the oldest saved copy of that page from June.

## Original Screenshot & Download

[Download the original JAR from my website, labeled 1.3](assets/zune-playlist-shuffler/zune-playlist-shuffler-1.3.jar)

This is the original Java program, exactly as it was. It does change your playlist files, so the instructions above still apply. I haven't tested it with current versions of Java.

One fun wrinkle: the website file was named **1.3**, but its About text (and the source code I found) say **v2.0**. I've kept the download exactly as I found it. I don't know when that build replaced the earlier download, or whether 2.0 ever had its own public release.
